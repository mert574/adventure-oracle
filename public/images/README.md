# Original environment artwork

These images were generated for Adventure Oracle with the built-in imagegen
tool, then encoded as WebP for local delivery. They are not Open5e content or
Blizzard artwork. No external requests are needed to display them.

- `fantasy-gateway.webp`: ruined gateway environment, used behind account pages.
- `dungeon-gate.webp`: dungeon environment, used by the full-screen lobby.

The interface takes visual inspiration from early fantasy MMORPGs, including
the user's World of Warcraft Classic reference. The illustrations, SVG game
icons, and SVG cursors are original assets rather than copied game resources.

## Gateway prompt

Use case: stylized-concept. Asset type: wide fantasy RPG game lobby background,
1536x1024 landscape. Create original painterly dark fantasy environment concept
art: an ancient ruined stone gateway and tall castle above a misty valley, a
winding trail leading through dark pine forests, distant mountains beneath a
pale moon, tiny warm amber torch lights, mysterious magical atmosphere. Rich
detailed hand-painted game loading-screen illustration. Composition: castle and
arch concentrated on right half, left half mostly dark mist and forest
silhouettes providing readable space for overlaid interface text. Palette
midnight blue, desaturated teal, moss, antique gold torch light. Cinematic depth,
restrained lighting. No text, no interface elements, no logos, no watermark.
Entirely original environment.

## Dungeon prompt

Use case: stylized-concept. Asset type: original classic fantasy MMORPG dungeon
environment painting for a web game interface, wide landscape 1536x1024.
Interior of an ancient medieval stone dungeon: monumental vaulted gate in
center-right, worn carved stone steps leading toward a glowing turquoise magical
portal, massive rough-hewn stone blocks and hanging iron chains, two burning
orange wall braziers, skeletal remains and scattered rusty swords on floor,
deep shadows. Hand painted stylized 2004-era fantasy game loading-screen
aesthetic, readable chunky shapes, believable stone, moody warm amber flames
against eerie teal magic. Dark vignette and shadowy negative space on left third
for overlaid title. Atmospheric drifting dust, dramatic perspective, immersive
dungeon exploration mood. No text, logos, UI, watermarks, or existing game
characters or franchise symbols.
